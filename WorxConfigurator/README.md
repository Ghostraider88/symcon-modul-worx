# Worx Configurator

The configurator lists cloud devices whose reports contain a complete, supported protocol-0 weekly schedule. This schedule-format check is not a claim that every device using protocol 0 is supported.

New mower instances are locked by default. In the local configurator, enable only a device that has been verified to match the supported V1 scope. Unknown or unsupported devices remain blocked.

The local device selection is used only by IP-Symcon and is not sent to another service. Do not copy device identifiers or full cloud responses into public issue reports.

Existing mower instances are not deleted or modified by changing this configurator property.
